01

Overview & Defensive Pipeline

Vexora is an open-source, multi-layered security firewall and defense gateway engineered to detect, mitigate, and encapsulate adversarial prompt injection attacks, persona hijacking, jailbreaks, and indirect document injections in Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG) pipelines.

The gateway screens all inbound inputs through a three-stage sequential defense architecture:

  • Layer 1 — Heuristic Sanitizer: High-performance deterministic pattern matching, regex analysis, invisible unicode stripping, control token neutralizing, and delimiter boundary validation.
  • Layer 2 — ML Semantic Intent Classifier: Dual-pool TF-IDF and machine learning classification trained on adversarial injection datasets (including HuggingFace datasets) to predict attack probabilities.
  • Layer 3 — Cryptographic Encapsulation: Nonce-signed system boundary delimiters that isolate untrusted user and RAG payloads before reaching downstream model inference.
02

Zero Centralized Telemetry Guarantee

Vexora is deliberately designed to operate with zero external telemetry. When you run, host, or deploy Vexora:

  • We do not collect, track, or transmit your prompt inputs to any centralized Vexora servers or external database.
  • No analytics SDKs, advertising pixels, user tracking scripts, or profiling cookies are embedded in the application.
  • All defense layers—including the heuristic sanitizer and machine learning intent classifier—execute completely on your local machine or private cloud host.
Zero Data Retention Guarantee: Your prompts, attached RAG documents, and LLM responses are processed in-memory. They never leave your deployment boundary for analytical or commercial purposes.
03

Data Processed During Security Screening

When an inbound request is submitted to the Vexora gateway, the following data points are evaluated in real time:

  • User Prompt Text: Screened in-memory to detect adversarial override directives, privilege escalation, and exfiltration patterns. Once screened, the prompt is stored only in your active browser session audit log, which is discarded upon closing the tab or clicking "Clear Chat".
  • RAG & Tool Context: Document excerpts or tool payloads attached via retrieval pipelines are inspected for indirect prompt injection vectors before encapsulation.
  • System Instructions: Custom system instructions you define in the configuration dialog remain strictly inside your browser's local session memory.
04

Third-Party AI Model Providers

When a prompt passes defense screening, Vexora dispatches the sanitized and encapsulated request to the AI model provider you selected (Google Gemini, OpenAI GPT, Anthropic Claude, or local neural engines).

These requests travel over direct encrypted HTTPS connections from your environment to the provider's official API endpoints. Once delivered, data handling is governed by that provider's respective privacy policy:

  • Google Gemini: Governed by Google AI Studio & Google Cloud Privacy Terms.
  • OpenAI: Governed by the OpenAI API Platform Data Use and Privacy Policies.
  • Anthropic: Governed by Anthropic Commercial Terms of Service and Privacy Policy.
  • Vexora Local (Mock): Runs 100% offline inside your running instance with zero network egress.
05

API Key Security & Client Storage

Vexora provides flexible credential management designed to prevent credential exfiltration:

  • API keys configured in the UI toolbar are stored exclusively in your browser's HTML5 localStorage under client-side keys (e.g. vexora_api_key_gemini).
  • API keys are passed to the local backend gateway solely to authenticate outgoing HTTPS inference requests to the respective AI provider.
  • API keys are never written to disk, never logged to application logs, and never transmitted to any third party.
Client-Side Storage Isolation: You can clear your stored credentials at any time by clearing your browser cache or deleting the toolbar input.
06

Zero-Day Vulnerability Pool & Retraining

Vexora features an active feedback loop allowing security researchers and developers to report novel prompt injection samples. When you click Report Zero-Day Vulnerability in the Inspector drawer:

  • The adversarial sample is appended directly to data/feedback_loop.jsonl inside your own instance's filesystem.
  • The feedback sample is used exclusively for training your local classifier via the "Retrain Intent Model" feature.
  • No sample data is uploaded to public repositories or central servers without your explicit manual action.
07

Browser Extension Privacy

When using the companion Vexora browser extension to protect web chat interfaces (such as ChatGPT or Gemini Web), the extension forwards the prompt to your locally running Vexora defense endpoint (http://127.0.0.1:5000).

The extension requires access only to communicate with the local loopback server. No prompt text, web page history, or cookies are collected or relayed externally.

08

Open-Source Transparency & Contact

As an open-source project, Vexora's full source code is public and auditable. You are encouraged to inspect the repository, verify network traffic in your browser's Developer Tools, and review the defense engine implementation.

For inquiries, vulnerability disclosures, or contributions, please open an issue in the project's GitHub repository.
